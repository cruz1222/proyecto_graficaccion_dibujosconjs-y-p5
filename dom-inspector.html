¿Qué es el DOM?

El DOM (Document Object Model) es la representación en forma de árbol que el navegador construye a partir del HTML. El nodo raíz es <html>, del que cuelgan <head> (metadatos, estilos y scripts) y <body> (contenido visible). Cada etiqueta anidada es un nodo hijo de la que la contiene.

Esta página lee el código de cada archivo HTML del proyecto y dibuja su árbol. Haz clic en un nodo para abrirlo o cerrarlo.
