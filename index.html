La etiqueta <canvas> y el contexto 2D

La etiqueta <canvas> de HTML5 define un área rectangular en blanco dentro de la página. Por sí sola no muestra nada: es un lienzo sobre el que JavaScript dibuja píxeles. Sus atributos width y height fijan la resolución (por defecto 300×150).

<canvas id="lienzo" width="400" height="400"></canvas>

Contextos de renderizado

Para dibujar se pide al canvas un contexto de renderizado con getContext(). Los principales son:

  • "2d": API de dibujo bidimensional (formas, rutas, texto, imágenes, degradados). Es el que explicamos aquí.
  • "webgl" / "webgl2": gráficos 3D acelerados por GPU.
  • "bitmaprenderer": muestra imágenes ImageBitmap de forma eficiente.

Un mismo canvas solo puede tener un tipo de contexto a la vez.

Ejemplo con el contexto 2D

const ctx = document.getElementById("lienzo").getContext("2d");

ctx.fillStyle = "green";          // color de relleno
ctx.fillRect(50, 50, 100, 80);    // x, y, ancho, alto

ctx.beginPath();                  // iniciar una ruta
ctx.arc(250, 100, 40, 0, Math.PI * 2); // círculo: x, y, radio, ángulo inicial/final
ctx.fillStyle = "orange";
ctx.fill();

ctx.strokeStyle = "black";
ctx.lineWidth = 3;
ctx.beginPath();
ctx.moveTo(50, 250);
ctx.lineTo(350, 250);
ctx.stroke();

Conceptos clave

  • Sistema de coordenadas: el origen (0, 0) está en la esquina superior izquierda; x crece hacia la derecha e y hacia abajo.
  • Rutas (paths): beginPath(), moveTo(), lineTo(), arc() y closePath() describen una figura que luego se pinta con fill() o stroke().
  • Estilos: fillStyle, strokeStyle y lineWidth se aplican a lo que se dibuje después.
  • Transformaciones: translate(), rotate() y scale(), junto con save() y restore() para guardar y recuperar el estado.
  • Animación: se borra con clearRect() y se vuelve a dibujar en cada fotograma usando requestAnimationFrame().

Fundamentos de p5.js

p5.js es una librería de JavaScript para programación creativa, inspirada en Processing. Simplifica el trabajo con el canvas: crea el lienzo, ejecuta el ciclo de animación y ofrece funciones sencillas como ellipse() o fill(). Es la base de los dibujos de Khan Academy.

Estructura básica

function setup() {
  createCanvas(400, 400); // se ejecuta una vez al inicio
}

function draw() {
  background(220);        // se ejecuta ~60 veces por segundo
  fill(255, 0, 0);
  ellipse(mouseX, mouseY, 50, 50);
}

Ideas principales

  • setup() y draw(): preparación inicial y bucle de animación.
  • Formas: rect(), ellipse(), triangle(), arc(), line(), bezier().
  • Color: fill(), stroke(), noStroke(), background(); admite valores RGB, escala de grises y transparencia.
  • Interactividad: variables del sistema como mouseX, mouseY, mouseIsPressed y eventos como mousePressed().
  • Transformaciones: push(), pop(), translate(), rotate().
  • Utilidades: random(), map(), constrain(), lerp(), sin().

Modo global vs. modo instancia

En modo global las funciones están disponibles directamente, pero solo se puede tener un sketch por página. En este sitio usamos el modo instancia: cada dibujo es una función que recibe un objeto s (el sketch) y se monta dentro de un contenedor con new p5(sketch, "id"). Así pueden convivir cinco lienzos en la misma página.

const miSketch = (s) => {
  s.setup = () => s.createCanvas(400, 400);
  s.draw  = () => s.ellipse(s.mouseX, s.mouseY, 40);
};
new p5(miSketch, "contenedor");

Relación con canvas

p5.js usa por debajo el contexto 2D del <canvas>. Por ejemplo, ellipse() equivale a beginPath() + ellipse() + fill() + stroke(). Con drawingContext puedes acceder al contexto nativo desde p5.
